# WNDR identity

The cut-prism is an original compact angular mark with a single rising negative-space cut. The uppercase WNDR lockup uses drawn geometry rather than a font dependency.

- Ice blue: `#A9DFFF`
- Deep ink: `#09131F`
- Clear space: at least one eighth of the symbol's width on all sides.
- Small icons: use the provided 16, 24, or 32 pixel ink-backed variants; do not add glow, bevels, outlines, or gradients.
- Light backgrounds: use `wndr-prism-ink.svg`; dark backgrounds: `wndr-prism.svg` or `wndr-prism-white.svg`.
- Do not use the brand blue to replace Carbon chart palettes or semantic status colors.

`wndr-brand-concept.png` records the generated concept board. Production assets are derived from `wndr-prism.svg`; `scripts/generate-wndr-brand.py` generates transparent PNG, Windows ICO, macOS ICNS, and web icons. `wndr-lockup.svg` is the outlined uppercase lockup.
